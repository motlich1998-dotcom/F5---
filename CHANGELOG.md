# Changelog

Все заметные изменения в расширении «F5 — расшифровка переменных» документируются здесь.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [семантического версионирования](https://semver.org/lang/ru/).

## [1.2.0] — 2026-05-15

### Added
- Hover-«фартук» над лаунчером F5: при наведении на кнопку появляется быстрый
  шорткат `{…}` для шаблонизатора. Клик по самой F5 открывает расшифровщик
  как и раньше.
- Подсветка активного состояния: иконка `{…}` (и в фартуке, и в шапке
  расшифровщика) подсвечивается тёмным, когда шаблонизатор открыт — сразу
  видно, в каком он состоянии.
- Активное (последнее тронутое) окно автоматически выходит на передний план
  поверх соседнего — как у обычных окон в ОС. Реализовано через одинаковый
  базовый `z-index` у обоих окон и динамический класс `is-front` на mousedown.
- Загрузка пользователей (`/api/v4/users`) и групп (`/api/v4/account?with=users_groups`)
  в словарь домена. Во вкладке «Пользователь» шаблонизатора теперь видно ID каждого
  сотрудника и каждой группы, юзеры сгруппированы по своим отделам (как этапы под
  воронками); клик копирует ID. Помечаются админы и деактивированные аккаунты.
- ID пользователей и групп подсвечиваются как ID-подсказки в любом тексте
  (тултип показывает имя, e-mail и группу).
- Счётчики «Польз.» и «Группы» в попапе.

### Changed
- Шаблонизатор теперь полностью независимое окно: больше не закрывается вместе
  с расшифровщиком и не открывается автоматически при его запуске. Координаты
  и высота по умолчанию подбираются корректно даже если расшифровщик закрыт
  (правый нижний угол, фиксированная высота 420 px).
- Поиск в шаблонизаторе теперь учитывает имя группы и e-mail пользователя.

### Notes
- Эндпойнт `/api/v4/users` доступен только администраторам аккаунта; для
  не-админских токенов список пользователей будет пустым (расширение это
  обрабатывает молча, остальной словарь грузится как обычно). Группы
  (`users_groups`) тянутся через `/api/v4/account` и доступны всем.

## [1.1.0] — 2026-05-13

### Added
- В шаблонизаторе во вкладке «Воронки» этапы теперь сгруппированы под своими воронками
  с заголовком воронки и подсказкой «основная» для главной — больше нельзя перепутать одинаково
  названные стадии из разных воронок.
- Отображение версии расширения в шапке плавающей панели и в попапе (включая футер popup).
- В попапе появилась кнопка «Кнопка Аммы: показана/скрыта». Скрытие реализовано
  через CSS-инъекцию по стабильным `aria-label` (без привязки к хешированным CSS-классам
  amoCRM). Применяется и снимается мгновенно — перезагрузка вкладки не требуется.
- Файл `CHANGELOG.md`.

### Changed
- В шаблонизаторе при поиске для этапов в правой колонке теперь показывается их воронка
  («Этап · <Название воронки>»).

### Fixed
- Вложенные переменные внутри модификаторов (например, `:if(=,1,{{lead.sale}},{{lead.name}})`)
  теперь распознаются и интерактивны: на каждую можно навести мышь для подсказки и
  кликнуть, чтобы раскрыть. Реализовано через рекурсивный рендер содержимого аргументов
  модификатора.

## [1.0.0] — 2026-05-08

### Added
- Плавающая панель F5 для расшифровки переменных amoCRM/Kommo (`{{lead.cf(123)}}`,
  `{{contact.sf(...)}}`, `{{user.name}}` и т.п.).
- Шаблонизатор: список переменных аккаунта со вкладками («Сделка», «Контакт», «Компания»,
  «Каталоги», «Воронки», «Системные»), поиском, выбором модификатора и кликом для копирования
  в буфер обмена.
- Подсказки по модификаторам (`:df`, `:if`, `:case`, `:upc`, `:lc`, `:trim` и др.) с описанием
  и примерами.
- Распознавание «голых» ID (полей, воронок, этапов) и тултипы с расшифровкой.
- Перетаскиваемые и масштабируемые панели с сохранением размеров и положения.
- Обновление словаря через API текущего аккаунта (cookie/session) — никаких внешних запросов.
