# F5 — Расшифровка переменных (Chrome extension)

Расширение для amoCRM/Kommo, которое расшифровывает переменные шаблонизатора Команды F5 в **отдельной плавающей панели** на странице (как в одноимённом виджете). Никакой подсветки и тултипов поверх контента amoCRM не делает — все взаимодействия только в окне панели.

## Что умеет

- Тянет словарь аккаунта по cookie-сессии (custom_fields сущностей `leads`/`contacts`/`companies`, каталоги, воронки и их этапы).
- Подсказывает по любой переменной из шаблонизатора F5 (https://cmdf5.ru/manual/vars):
  - кастомные поля: `lead.cf(123)`, `lead.cfm(123)`, `lead.cff(123)`, `lead.sf(123)`, `lead.cfyur(123, name)`, `lead.previousCf(123)`, аналогично для `contact`/`company`;
  - каталоги/товары: `catalogElement(last, 3941).cf(264543)`;
  - системные переменные: `lead.name`, `lead.id`, `lead.status`, `date.now`, `date.tomorrow`, `users(<id>).name`, `random.str`, `client.name` и т.п.;
  - модификаторы (`:df`, `:calc`, `:format`, `:spell_price`, `:noun_decl`, `:fio`, `:if`, `:ifempty`, `:slice`, `:replace`, `:translit` и др.) — описание и примеры по клику/наведению.
- Распознаёт «голые» ID. Если в тексте встретилось число, которое уже есть в словаре домена (поле, воронка, этап, каталог), оно подсвечивается, и при наведении показывается, что это за объект.

## Как это работает

1. Когда вы открыли `*.amocrm.ru / *.amocrm.com / *.kommo.com`, content script делает same-origin `fetch` к `/api/v4/...` — браузер сам подставит cookie сессии. Явный access_token не нужен.
2. Загружается:
   - `/api/v4/leads/custom_fields`, `/api/v4/contacts/custom_fields`, `/api/v4/companies/custom_fields`;
   - `/api/v4/catalogs` + `/api/v4/catalogs/<id>/custom_fields`;
   - `/api/v4/leads/pipelines` (воронки и встроенные этапы).
3. Словарь складывается в `chrome.storage.local` под ключом `f5vr:dict[<host>]`. По нему резолвятся имена и типы.
4. В правом нижнем углу появляется кнопка **F5** — клик открывает плавающую панель.

## Панели

### Основная — расшифровка
- Текстовое поле и предпросмотр в реальном времени.
- Hover по переменной — тултип с именем/типом поля или описанием системной переменной.
- Hover по модификатору — описание и примеры из мануала.
- Клик по переменной — раскрывает её в `{Сущность: Имя поля (Тип)}` или подставляет описание системной. Повторный клик — назад.
- Перетаскивается за шапку, тянется за края (8 направлений). Размер и положение запоминаются.

### Шаблонизатор переменных
- Открывается из шапки кнопкой `{…}`.
- Список всех переменных аккаунта с поиском и категориями (Сделка, Контакт, Компания, Клиент, Воронки, Каталоги, Дата, Пользователь, Случайное). Пустые вкладки скрываются.
- Селектор модификатора — добавляет к выбранной переменной нужный модификатор перед вставкой.
- Клик по строке — вставка переменной в текстовое поле основной панели в позицию курсора.
- Воронки и этапы помечены бейджем `ID` — это не самостоятельные переменные, их id используется как аргумент, например `{{contact.leadsCount(<id_воронки>/<id_этапа>)}}`.
- Перетаскивается и тянется за края (как и основная). Если задать свой размер — он сохраняется и больше не подстраивается под высоту основной.

## Когда обновляется словарь

- Автоматически при первом заходе на домен; далее не чаще раз в 24 часа (TTL).
- Вручную — кнопка ⟳ в шапке панели или «Обновить словарь» в попапе расширения.

## Обновление самого расширения (без `chrome://extensions` и без терминала)

Начиная с **v1.3.0** расширение умеет обновляться **в один клик прямо из попапа**, без ручного скачивания ZIP, распаковки и нажатия ⟳ на странице расширений. Это работает за счёт File System Access API — расширение само пишет свежие файлы в свою же папку на диске, после чего перезапускает себя через `chrome.runtime.reload()`.

### Как это выглядит

1. Service worker раз в 12 часов проверяет `manifest.json` в ветке `main` репозитория.
2. Когда находит более свежую версию — в попапе расширения вверху появляется голубой баннер «Доступна версия X.Y.Z → Обновить».
3. Клик «Обновить» открывает отдельное окно-визард с шагами:
   - проверка папки расширения;
   - запрос разрешения на запись;
   - скачивание архива;
   - распаковка;
   - запись файлов;
   - перезапуск расширения.
4. После последнего шага расширение само перезагружается, как если бы вы вручную нажали ⟳ в `chrome://extensions`.

### Первый запуск (один раз)

При самом первом клике «Обновить» расширение попросит выбрать папку, в которой лежит `manifest.json` — **ту самую**, которую вы указали Chrome'у при «Загрузить распакованное». Выберите её через системный пикер. После этого расширение запомнит папку (хэндл хранится в IndexedDB) и больше не будет про неё спрашивать.

### Что нужно знать про разрешения Chrome

Это особенность самого Chrome, а не наша: при **каждом перезапуске браузера** при первом обновлении сверху страницы появится серая полоска **«Разрешить F5 — расшифровка переменных просматривать и редактировать файлы в папке "F5---"?»**. Один клик «Разрешить» — и до конца сессии браузера запросов больше не будет. Это нельзя ни обойти, ни ускорить — таково ограничение API.

### Кнопка «Проверить обновления»

В футере попапа есть ссылка «Проверить обновления» — ручной запуск проверки прямо сейчас, без ожидания фонового алярма. Рядом появляется состояние («проверяю…», «доступно X.Y.Z», «актуальная»).

### Если что-то пошло не так

В окне обновления при ошибке доступны три кнопки:

- **Повторить** — попробовать тот же шаг ещё раз (например, после клика «Разрешить» в полоске Chrome).
- **Сменить папку** — заново выбрать папку (если оригинальная переехала или вы загружали расширение из другого места).
- **Скачать вручную** — открывает страницу репозитория, чтобы скачать архив руками. Дальше — старый путь: распаковать поверх + ⟳ в `chrome://extensions`.

### Когда автообновление не работает

- В браузерах без File System Access API (Firefox, Safari, очень старый Chrome) визард сразу покажет пояснение и предложит ручной путь.
- Если вы передвинули или переименовали папку расширения после первой привязки, нажмите «Сменить папку» в окне обновления.

### Какие данные уходят наружу

- Раз в 12 часов — один GET-запрос на `raw.githubusercontent.com`, забирает только маленький `manifest.json` для проверки версии.
- При нажатии «Обновить» — один GET на `api.github.com` (он же `codeload.github.com`) за zipball'ом ветки `main`.
- Никакие данные клиента / cookie / содержимое страниц amoCRM наружу не уходят.

## Попап расширения

- **Обновить словарь** — повторный пулл из API.
- **Открыть панель** — открывает панель на текущей вкладке (включит её, если была отключена).
- **Панель: вкл/выкл** — показывать ли кнопку запуска панели на страницах.
- **Амма: показана/скрыта** — скрывает/возвращает кнопку «Открыть чат с Аммой» и её всплывающие подсказки по сделкам на страницах amoCRM. Применяется мгновенно, перезагрузка не требуется.
- **Очистить домен** — стирает словарь только текущего домена.
- **Все домены в хранилище** — список доменов и количество полей в каждом.

## Установка в Google Chrome (распакованное расширение)

Расширение пока не публикуется в Chrome Web Store — устанавливается вручную из исходников. Это занимает 1–2 минуты.

### 1. Скачайте код расширения

- **Если у вас нет git:** на странице репозитория [F5---](https://github.com/motlich1998-dotcom/F5---) нажмите зелёную кнопку **Code → Download ZIP**, скачается архив `F5---main.zip`.
- **Если у вас есть git:** `git clone https://github.com/motlich1998-dotcom/F5---.git`.

### 2. Распакуйте архив

Откройте `F5---main.zip` и распакуйте его в любую постоянную папку, например `~/F5-extension/` или `Documents/F5/`.

> ⚠️ Важно: **не удаляйте эту папку** после установки — Chrome подгружает расширение прямо из неё. Если папку перенести или удалить, расширение перестанет работать.

После распаковки внутри будет папка с проектом, а в ней — поддиректория **`F5 Расшифровка переменных - расширение`**. Эта поддиректория с файлом `manifest.json` внутри и есть «папка расширения» — её мы и подсунем Chrome.

### 3. Откройте список расширений Chrome

В адресной строке Chrome введите и перейдите на:
```
chrome://extensions
```

(Edge — `edge://extensions`, Yandex Browser — `browser://extensions`, Arc — то же `chrome://extensions`.)

### 4. Включите «Режим разработчика»

В правом верхнем углу страницы расширений найдите тумблер **«Режим разработчика» / «Developer mode»** и включите его. Появится дополнительная панель с тремя кнопками: **«Загрузить распакованное»**, «Упаковать расширение», «Обновить».

### 5. Загрузите расширение

Нажмите **«Загрузить распакованное» / «Load unpacked»** → в открывшемся диалоге выберите ту самую папку **`F5 Расшифровка переменных - расширение`** (где лежит `manifest.json`), и нажмите «Открыть».

В списке расширений появится «**F5 — расшифровка переменных (amoCRM)**» с зелёным переключателем.

### 6. Закрепите иконку (опционально, но удобно)

Нажмите на значок «пазла» 🧩 в правом верхнем углу Chrome → рядом с «F5 — расшифровка переменных» нажмите на «канцелярскую кнопку» 📌. Иконка переедет на постоянное место в панели браузера.

### 7. Откройте amoCRM-аккаунт клиента

Зайдите на любой `*.amocrm.ru` / `*.amocrm.com` / `*.kommo.com`. В правом нижнем углу появится тёмная кнопка **F5**:

- **Клик по F5** — откроет окно расшифровщика.
- **Наведение на F5** — над кнопкой появится шорткат `{…}`, клик откроет шаблонизатор переменных.
- При первом заходе на этот домен расширение автоматически подтянет словарь полей по cookie-сессии. Можно дополнительно нажать «**Обновить словарь**» в попапе расширения, если нужно.

### Обновление до новой версии

Когда на GitHub выйдет новый релиз:

1. Скачайте свежий ZIP (или сделайте `git pull` в папке репозитория).
2. **Распакуйте поверх** старой папки (`F5 Расшифровка переменных - расширение`), заменяя файлы.
3. На странице `chrome://extensions` найдите карточку «F5 — расшифровка переменных» и нажмите кнопку **обновления** (круглая стрелка ⟳ на самой карточке) — или просто нажмите общую кнопку **«Обновить»** наверху страницы.
4. Готово, новая версия активна. Перезагружать вкладку amoCRM не обязательно, но иногда полезно — content script подцепится с чистым состоянием.

### Удаление

`chrome://extensions` → карточка «F5 — расшифровка переменных» → **«Удалить»**. Локальный словарь (`chrome.storage.local`) тоже удалится.

## Установка в Яндекс.Браузер (распакованное расширение)

Принципиально не отличается от Chrome — Я.Браузер тоже на Chromium, тот же Manifest V3. Важное отличие — путь и порядок включения «Режима разработчика».

### 1. Распакуйте архив

Скачайте репозиторий [F5---](https://github.com/motlich1998-dotcom/F5---) (зелёная кнопка **Code → Download ZIP**) и распакуйте его в постоянную папку (Я.Браузер подгружает расширение прямо из неё, удалять/двигать папку нельзя). Внутри найдите поддиректорию **`F5 Расшифровка переменных - расширение`** с файлом `manifest.json` — её и подсовываем браузеру.

### 2. Откройте управление расширениями

В адресной строке Я.Браузера введите:
```
browser://extensions/
```
Откроется страница «Дополнения / Расширения».

### 3. Перетащите папку в окно браузера

Просто перетяните папку **`F5 Расшифровка переменных - расширение`** прямо на эту страницу. Я.Браузер добавит расширение в список, но **в выключенном состоянии** — это нормально.

### 4. Включите «Режим разработчика» и активируйте расширение

1. На той же странице зайдите в карточку добавленного расширения «F5 — расшифровка переменных» (клик по названию или кнопке «Подробнее»).
2. В правом верхнем углу страницы найдите тумблер **«Режим разработчика»** и включите его.
3. Только после включения режима разработчика появится возможность активировать само расширение — переключите его тумблер во «вкл».

> ⚠️ В Яндекс.Браузере без активного «Режима разработчика» распакованное расширение просто не запустится — даже если оно уже добавлено в список. Это поведение самого браузера, не наше ограничение.

### 5. Откройте amoCRM-аккаунт

Зайдите на любой `*.amocrm.ru` / `*.amocrm.com` / `*.kommo.com` — в правом нижнем углу появится кнопка **F5**. Клик — расшифровщик, наведение — шорткат `{…}` для шаблонизатора. Дальше всё как в Chrome.

### Обновление и удаление

- **Обновление:** распакуйте новый ZIP поверх старой папки и нажмите «Обновить» на карточке расширения в `browser://extensions/` (или общую кнопку «Обновить» наверху страницы).
- **Удаление:** на той же странице → «Удалить». Локальное хранилище расширения (словарь домена) тоже стирается.

## Безопасность

- Запросы идут только к API того же домена, на котором вы уже залогинены. На сторонние серверы данные не уходят.
- Cookie никогда не читается явно — браузер подставляет её сам в same-origin `fetch`.
- Словарь хранится локально в `chrome.storage.local`. Очистить можно кнопкой «Очистить домен» или удалением расширения.
